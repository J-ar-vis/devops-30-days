# DevOps 30-Day Learning Log

## Day 1 - What is DevOps + Mac setup
- Learned:
  - DevOps bridges software development and IT operations to shorten deployment cycles and improve delivery speed.
  - Automation, continuous integration, and continuous delivery (CI/CD) are essential to maintaining reliable infrastructure.
  - Setting up local development tools properly is the foundation for hands-on DevOps practice.
- Tools installed: Homebrew, Git, VS Code, Docker, Multipass
- Commands: whoami, pwd, ls, brew install, multipass shell
- Broke/Fixed: Switching between Mac terminal and Ubuntu Linux environment required using `cat` instead of `pbcopy` for SSH key setup.
- Interview Q: Explain DevOps in 2 minutes (answer below)
  - DevOps is a methodology that combines software development (Dev) and IT operations (Ops). It focuses on automation, continuous integration, continuous deployment, and culture shift to deliver updates quickly, reliably, and with high quality.
